## Paperless Backup Programm

Mit seinen Eigenentwicklungen möchte Ralf-Peter Kleinert auch Menschen mit wenig technischer Erfahrung den Zugang zu praktischer IT erleichtern. Ein Beispiel ist das Paperless Backup Programm für Windows: Es vereinfacht die Einrichtung und Pflege der digitalen Dokumentenverwaltung Paperless-ngx und bündelt Installation, Aktualisierung, Datensicherung, Wiederherstellung und Migration in einer grafischen Benutzeroberfläche.

Damit können auch Anwender ohne tiefgehende Docker-Kenntnisse oder Erfahrung mit der Kommandozeile Paperless-ngx nutzen. Eine ausführliche Anleitung und ergänzende Video-Tutorials helfen beim Einstieg.

Das Programm ist für Paperless-ngx unter Windows mit Docker Desktop vorgesehen. Hinweise zur unterstützten Installation und zur jeweiligen Version stehen auf den offiziellen Programmseiten.
